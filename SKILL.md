# Research group website requirements

## Current goal

This is a fictional practice site for learning local editing and GitHub. Keep the pages small and easy for a beginner to edit. Do not replace the mockup with real group information until asked.

## Working rules

- Read this file before changing the site.
- Use the existing checkout. Cloud tasks already have an isolated workspace; do not create a Git worktree unless explicitly requested.
- Keep the current site as plain HTML and CSS unless the owner asks to change tools.
- Keep Home, People, Research, and Publications linked from every page.
- Use relative links, readable text, keyboard-accessible navigation, and a layout that works on phones.
- Explain which files changed and give a small editing exercise when useful.
- Validate local page and stylesheet links after edits.
- Ask before publishing or inviting collaborators unless already explicitly authorized.
- Never put credentials in the website or these instructions.
